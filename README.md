## 📌 Overview

**CodeMentor** is an IT preparation hub designed to bring structured learning, coding practice, technical interview preparation, and progress tracking into one platform.

It provides a centralized interface for students to explore learning paths, study technical topics, practise Data Structures and Algorithms, prepare for interviews, and organize their development journey.

The project follows a developer-focused interface with a refined visual design, responsive navigation, and dedicated learning environments.

## ✨ Features

### 📚 Learning and Development
- Student dashboard with learning metrics and daily goals.
- Structured learning paths for Java Backend, Full Stack Development, Frontend Architecture, and DSA.
- Dedicated course detail and curriculum views.
- Interactive lesson-reading interface.
- Curated technical courses and learning resources.

### 💻 Coding Practice
- DSA problem collection with topic-based organization.
- Problem search and difficulty filters.
- Java, Python, and C++ starter code examples.
- Coding challenge interface.

### 🎯 Interview Preparation
- Technical interview preparation sections.
- Topic-based interview practice.
- Structured preparation resources.

### 📊 Progress and Organization
- Learning activity contribution heatmap.
- Course progress indicators.
- Daily learning goals.
- Bookmarks and saved resources.
- Student profile and account settings.

### 🎨 User Interface
- Deep emerald and warm ivory design system.
- Editorial typography and developer-oriented visual hierarchy.
- Fixed sidebar and top navigation.
- Independently scrollable main content.
- Responsive navigation for smaller screens.
- Sign-in and registration interface.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension (recommended).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Swetagupta05/CodeMentor.git
```

**2. Navigate to the project directory**

```bash
cd CodeMentor
```

**3. Open in Visual Studio Code**

```bash
code .
```

**4. Run the application**

Open `index.html` using Live Server.

Alternatively, open `index.html` directly in your browser.
